# AnvilCraft:AutoTree

铁砧工艺的自动补料扩展，适用于 Minecraft 1.21.1、NeoForge 21.1.x、AnvilCraft 1.6.x 和 JEI。模组需同时安装在客户端和服务端。[下载最新版](https://github.com/MeBone/AnvilAutoTree/releases/latest)

## 功能

- JEI 紫色「+」打开可拖动、缩放的合成树，预览材料、库存和缺口，支持空格确认。
- 超维存储单次最多下单 1024 次，潜影集装箱最多 64 次。大型板条箱和本地终端支持单次补料。
- 超维存储和潜影集装箱可合并多套多方块配方的材料，按堆叠上限分装到空潜影盒并放入合成表。空盒或空槽不足时会显示缺口。
- 生存模式持有绑定的超维终端时，缺货的方块可以通过世界内中键打开合成树。普通成品切换至主手，多方块材料包装入背包。

## 模组配置

客户端窗口位置和大小可在 **AnvilCraft:AutoTree → 配置 → 客户端** 中拖动预览并保存。

通用配置文件为 `config/anvilautotree-common.toml`。

| 配置项 | 默认值 | 说明 |
| --- | ---: | --- |
| `parallel` | 1024 | 超维每刻合成上限。潜影为超维的 1/12，板条箱为潜影的 1/12，向下取整，最低 1 次 |
| `maxDepth` | 16 | 合成链最大深度 |
| `maxSteps` | 256 | 单份合成计划的最大步骤数 |
